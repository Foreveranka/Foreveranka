### 🏦 [Troia](https://github.com/Foreveranka/Troia)

Pay in lira with an ordinary Troy card, the merchant receives USDC. Nobody in the flow holds a wallet or learns what a seed phrase is. On Stellar. [Docs](https://troia-docs.vercel.app)

Rebuilt three times as the ground moved: Monad first, then [Arc](https://github.com/Foreveranka/Troia-Arc), now Stellar.

### ⚓ [Helm](https://github.com/Foreveranka/Helm-Arc)

A marketplace for agent-managed USDC vaults. Anyone launches a fund, an autonomous agent runs the strategy, and the contract gives that agent no function that sends money to an arbitrary address. Investors hold an ERC-4626 share token that tracks real profit and loss.

The founder uploads the bot they say they run, the browser hashes it, and the vault seals that hash on chain, so a quiet swap later shows up as a version bump. Arc testnet. [Live](https://helm-arc.vercel.app)
